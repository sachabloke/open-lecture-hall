# Open Lecture Hall

A free, searchable catalogue of university lecture courses and podcasts you can watch or listen to with no sign-up and no payment: MIT OpenCourseWare, NPTEL (IITs), Yale, Oxford, Stanford, UC Irvine, Saylor and many more. Where a university took its lectures down (for example UC Berkeley's webcasts), it links to the copy preserved on the Internet Archive.

The site is static: `index.html` plus `courses.json`. All lectures belong to their institutions; this site only links to them.

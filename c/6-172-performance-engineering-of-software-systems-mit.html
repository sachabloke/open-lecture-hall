6.172 Performance Engineering of Software Systems

Charles Leiserson, Julian Shun · 2018 · 23 free video lectures

6.172 is an 18-unit class that provides a hands-on, project-based introduction to building scalable and high-performance software systems. Topics include performance analysis, algorithmic techniques for high performance, instruction-level optimizations, caching optimizations, parallel programming,…

Functional Programming with OCaml

Prof. K C Sivaramakrishnan · 73 free video lectures

This course introduces the principles of functional programming using OCaml, with a strong emphasis on building reliable and secure software systems. It covers core concepts such as higher-order functions, type systems, and modular design, along with advanced topics like concurrency and memory…

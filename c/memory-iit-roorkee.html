Memory

Prof. M. K. Asthana · 40 free video lectures

In this course, we propose a basic understanding of the memory process. The course lectures will introduce the student to the fundamental rule that determines memory processes through a historical perspective. We will present several paradigms used to date to investigate memory consolidation…

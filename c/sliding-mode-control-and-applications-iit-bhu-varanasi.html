Sliding Mode Control and Applications

Prof. Shyam Kamal · 60 free video lectures

This course introduces Sliding Mode Control and Applications, focusing on advanced control methods for systems under heavy uncertainty. It builds upon classical mathematical-control theory, which typically solves control problems asymptotically, by presenting techniques that provide exact solutions…
